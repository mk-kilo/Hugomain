BEFORE YOU SIGN UP

注册前最常见的问题

需要先在 JXZNE 注册账号吗？

不需要。JXZNE 提供免费的工具选择和配置教程。需要 API 时，直接前往 Ofox 官方网站注册，账号、充值和 API Key 都由服务平台管理。

ChatGPT 或 Claude 的订阅能当作 API 余额使用吗？

通常不能。聊天产品订阅与 API 调用一般分别计费；第三方平台也有独立的账户与余额。请核实自己的采购方式。

不充值可以完成配置测试吗？

可以先了解配置方式，但实际模型调用可能需要有效余额。Ofox 的促销、赠额及计费规则以其当前官方页面为准，不保证无充值即可调用。

能否直接在 Cursor 中使用第三方 API？

并非全部 Cursor 功能都支持自定义 API。可在 Cursor 终端配置其他兼容的 CLI 工具；实际能力依赖客户端版本和提供商。

可使用中国银行卡吗？必须使用 VPN 吗？

支持的付款方式、国家或地区及访问限制可能变化。请以服务商结算页面和当地法规为准；本站无法保证特定银行卡或网络环境下支付成功。

为什么本网站不收集 API Key？

API Key 是敏感凭证，只应在受信任的服务商、你自己的设备或安全后端使用。不要在 JXZNE 的网页或其他不可信表单输入真实密钥。
