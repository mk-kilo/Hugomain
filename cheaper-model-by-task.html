按任务比较，而不是按广告选更低的单价

更省指的是：同一件工作，结果还能用，并且按你抄到的单价算出来的账单更低。本页不公布模型排行，不写省下的百分比，也不说某一家一定更便宜。Ofox 是否低于原厂标价，要拿同一模型、同一用量去对，而不是从这里读一个结论。

五步，用你自己的样本

  1. 用一句话写下任务。例如抽取字段、改写、翻译、改一段代码，或读一份长文档后回答一个问题。
  2. 从目录里选两个真实存在的 id，不要凭记忆。读法在 模型列表。两个 id 必须都能走你实际调用的那个端点。
  3. 用同一小段输入各调用一次。你自己判断失败是否还能接受：字段错了、没跟上指令，或代码不能用。本站没有分数。
  4. 打开服务商当前的价目页，抄下这两个 id 的输入单价和输出单价，单位是每百万 token。缓存、批处理和长上下文如果另计价，单独记下来，不要并进一个“更便宜”。
  5. 把每月 token 填进 月费计算器。计算器可以从带日期的 Ofox 公开目录预填一个方案的单价；另一个方案和任何官方标价仍要你自己填。没填的单价不会被算进去。差额只是减法，不是省下的百分比。

常见问题

单价更低是不是就更省？

只有你的样本结果还能用时才是。输出不可用时，重试和人工修改都是额外成本。本页不把任何模型写成更便宜。

为什么页面上没有模型排行？

排行需要价格和效果数字。本站不发明这些数字。你从服务商价目页抄来的单价，填进 月费计算器，才是你自己的比较。
