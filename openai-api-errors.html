401 Unauthorized

401 表示这把凭证被拒绝。按下面四项核对，不要先换模型。

  1. 请求头是 Authorization: Bearer，然后一个空格，然后密钥。不要写成 Bearer Bearer，不要给密钥加引号。
  2. 粘贴时去掉首尾空格和换行。从网页复制密钥时，末尾经常多一个换行。
  3. 密钥必须属于你填写的那个根地址。发给 api.openai.com 的密钥不能调用 api.ofox.ai，反过来也不行。
  4. 到签发这把密钥的控制台确认它没有被撤销，并且账户允许调用。

不要把密钥贴到本站、工单、聊天记录或 Git 仓库。示例里只应出现 YOUR_API_KEY 或环境变量。

429

429 表示服务端要求你降低请求频率，或者当前容量不够。它不是一张价目，也不能从这里读出“贵了多少”。

  1. 看是不是开了过高的并发，或者失败后立刻重试、没有间隔。
  2. 如果响应头里有 Retry-After，按那个秒数等待。没有这个头时，本页不另给一个秒数。
  3. 正文如果在说额度或账单，打开服务商控制台看余额和限额。不同服务商用不同的状态码表示欠费。本页不把某一个码指定成 Ofox 的欠费码。

超时

多数“超时”是客户端先放弃，不是服务端返回的 HTTP 状态。先看报错来自哪里。

  1. 客户端库写 timeout：这是你的等待上限短于这次生成。官方 OpenAI SDK 的构造参数里有 timeout（Python 与 Node 都有）。把它调到这次回答需要的时间以上。本页不写一个固定秒数。
  2. HTTP 408 或 504：这是链路上的状态。先确认根地址能打开，再看你和 api.ofox.ai 之间的网络。本站没有一份延迟表。
  3. 长回答看起来像卡住：Chat Completions 请求体可以带 stream: true，服务端按块返回。这是协议字段，不是本站测得的加速数字。

常见错误

401 Unauthorized 先查什么？

确认 Authorization 是 Bearer 加一个空格再加密钥，密钥没有多余空格、换行或引号，并且这把密钥属于你填写的那个 Base URL 的账户。OpenAI 的密钥不能调用 api.ofox.ai，反过来也不行。不要把密钥贴到公开页面。

404 或 model not found 先查什么？

SDK 的根地址用 https://api.ofox.ai/v1，不要再加 /chat/completions。curl 的完整地址只含一次 /chat/completions。模型 id 必须来自该服务商的目录，例如 openai/gpt-5.4。只提供 Responses 的模型用 Chat Completions 去调，也可能是 404。

429 是不是表示价格不对？

不是。429 表示服务端要求降低频率或当前容量不足。先降低并发，并在响应有 Retry-After 时按那个秒数等待。余额问题看服务商控制台，本页不指定 Ofox 的欠费状态码。

超时是不是服务端的一种 HTTP 状态？

多数时候是客户端先断开。先分清客户端 timeout 和 HTTP 408 或 504。官方 SDK 可以调大 timeout，本页不给固定秒数。需要边生成边返回时，Chat Completions 有 stream 字段。

工具侧的短说明仍在 配置教程。编程工具和这里的 HTTP 调用不是同一条路径。模型 id：列表接口。请求形状：Python / Node / curl。

密钥本身要先能签发

401 有时只是因为还没有这把密钥。账号在 Ofox 创建。
