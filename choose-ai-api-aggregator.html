HOW TO CHOOSE

第三方 AI API 聚合商怎么选

聚合商的用处是少开几个账户、少管几把 Key，不是一张自动更低的价目表。只调用一个模型、或者合同必须和原厂签的时候，官方 API 往往更合适。下面四步用的都是本站已经公开的对照和验证状态，不新编手续费，也不给 Ofox 加“已验证”。

先看官方 API、Ofox、OpenRouter 对照 → 再看哪些调用还没测通 →

四步，按顺序做

1 · 数模型，不数广告

长期只用一个模型：留在原厂，企业折扣也可能更好。经常在 GPT、Claude、Gemini 之间切换：再把聚合账号放进候选。便利要靠你自己的调用清单证明，不靠首页上的模型数量。

2 · 写下客户端要的协议

自己的 OpenAI SDK 程序、Codex、Claude Code、Cursor，要的接口不是同一个。Ofox 文档列出 OpenAI 兼容（Chat Completions / Responses）、Anthropic Messages 和 Gemini generateContent。某个模型有没有那个端点，以模型卡片为准。本站没有替你打通。

3 · 把 Cursor 的功能单独划出去

Ofox 在 2026-10-16 的说明里把直接接入 Cursor 标成不合适。Tab、Background Agent、Auto 不会跟着自定义供应商走。选聚合商解决不了这个限制。细节在 Cursor / Codex 用不了第三方 API 怎么办。

4 · 核对账单和文件，再充值

对照页记录的是 2026-10-29 读到的公开说法：Ofox 称按厂商标价、平台手续费 0%，并有返还档位说明；OpenRouter 定价页当时写了另一套平台费。这些是他们的页面，不是本站审过的发票。DPA、数据驻留或发票必须跟原厂签时，先要文件。

常见问题

聚合商是不是一定比官方 API 便宜？

不一定。Ofox 自己的说法是按厂商标价计费、平台手续费 0%。原厂仍可能给你合同折扣。本站没有审过你的账单，所以不写“更便宜”。

OpenRouter 的平台费能直接套到 Ofox 上吗？

不能。对照页把 OpenRouter 定价页上的档位记成他们自己的公开价目，并写明查阅日。每家的手续费分开看。

选了聚合商，Cursor 的 Agent 就会跟着走吗？

Ofox 写明不会。Tab、Background Agent 和 Auto 不走自定义供应商。换一家聚合商也不会自动补上 Cursor 的这些功能。
