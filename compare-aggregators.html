什么时候不要用聚合

你只用一个模型

原厂账号更简单，企业折扣也可能更好。聚合的价值主要在“多家模型一个账单”。

你要 Cursor 的 Tab / Agent / Auto

Ofox 已经说明这些不走自定义 API。换一家聚合也不会自动补上 Cursor 的官方功能。

合规要求直签原厂

如果 DPA、数据驻留或发票必须和模型厂商直接签，中间商条款可能不够。先要文件，再充值。

工具还没在你机器上跑通

本站的 Codex CLI 和 Claude Code 目前是未验证。tests/ofox_smoke.py 没在这里记录通过，而且它本来也不启动这两个客户端。

标价和结算页不一致

宣传页上的 0% 手续费、返还或赠额，都以结账时的规则为准。对不上就别按宣传页做预算。

你把聊天会员当成 API

ChatGPT、Claude 或 Cursor 的订阅通常不能当作第三方 API 余额。买 API 额度也不会自动开通这些订阅。
