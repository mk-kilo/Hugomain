自己的程序，和编辑器不是同一题

如果你写的是服务端，用的是 OpenAI SDK，要改的是 Base URL、Key 和模型名。这跟 Cursor 的 Tab 无关。Ofox 文档列出 Chat Completions 和 Responses。你的代码走哪一个，就核对哪一个端点。价格仍要你自己在对方页面看。开发者页在没填单价时不会显示省了多少钱。

常见问题

为什么充了 API 额度，Cursor Tab 还是不动？

Tab、Background Agent 和 Auto 按 Ofox 的说明不走自定义供应商。额度买的是 API 调用，不是这些编辑器功能。

能不能把一份 Ofox 的 Codex 配置直接贴进 config.toml？

本站不提供。协议、模型 id 和认证方式对不上就会报错。先读官方配置文档，再向 Ofox 确认他们当前写明支持的端点。

Claude Code 是不是已经测通了？

没有。验证页把它标成待验证。tests/ofox_smoke.py 不启动 Claude Code。需要 Anthropic 兼容网关，不能把只支持 OpenAI 的 /v1 填进 ANTHROPIC_BASE_URL。
