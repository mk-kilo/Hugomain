CHAT PLAN VS API

Chat subscription vs API billing

ChatGPT Plus, Claude Pro, and a developer API are different products. The subscription buys the chat app’s plan. The API bills tokens on another account, with its own key. This page explains that split, shows the Ofox catalog observation already stored in this repo, and calculates a monthly bill only from rates you type in.

What should influence the decision

One provider

Direct API access fits a workload that depends on a single model or on the lab’s own support.

Several model families

An aggregator can put keys and invoices in one place. Confirm the protocol and the rate you were quoted. How to choose.

A coding client

Cursor direct use is marked unsuitable by Ofox. Codex and Claude Code are unverified on this site. Read the evidence before a large top-up. Setup guides.

Questions

Why are the calculator rates blank?

A blank field means this page will not invent a rate. Type a number you checked on the lab’s page or on Ofox. The observation table above is dated 2026-10-29 and only covers four requested ids.

Does a passing smoke test change these prices?

No. Verification records whether an authenticated call returned model content. It is not a price, a latency, or a success rate. The status file stays unverified until that test passes.
