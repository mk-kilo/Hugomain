How country samples sit next to the list price

  2. Read the observation date. A sample is not today’s receipt.
  3. A blank country stays blank. Do not copy a neighbor’s number into it.

Questions

Is Claude Pro $20 a month or $17?

The Claude page records both official list prices: $20 monthly, or $17 a month when you pay $200 once for the year. That is billing cadence, not two countries. Store samples live in the matrix.

Does Pro include API credit?

The product page attaches “API credit each month” to Max ($100) and Ultra ($200), and it attributes that sentence to the official page. Do not move those sentences onto Pro. Developer calls use the API price list.

Can this table include Ofox’s Claude price?

Not from nothing. The 2026-10-29 unauthenticated catalog did not include a text rate for claude-sonnet-4.6. Check the model id and the rate on Ofox’s current page before you compare it with the official API.
