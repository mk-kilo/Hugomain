What the script calls

Ofox’s OpenAI-compatible base URL is https://api.ofox.ai/v1. Chat Completions is POST https://api.ofox.ai/v1/chat/completions with Authorization: Bearer and the raw key. Chat Completions · Quick start

The same run also sends one minimal request to each of the other two protocols. Responses is POST https://api.ofox.ai/v1/responses with Authorization: Bearer. The default model is qwen/qwen-flash. Anthropic Messages is POST https://api.ofox.ai/anthropic/v1/messages with x-api-key and anthropic-version: 2023-06-01. That default model is qwen/qwen-flash as well. Output is capped at 16 tokens. A failure in one call does not skip the others. Responses · Messages

Responses and Messages results are stored on their own checks. The verification page shows a recorded pass only after that check is recorded as successful. Otherwise the row stays not verified. The table above is still the Chat Completions call.

The public catalog fetched on 2026-11-12 (GET /v1/models, 131 ids) includes openai/gpt-5.4 and does not include openai/gpt-5.6. The 5.6 ids in that response were openai/gpt-5.6-sol, openai/gpt-5.6-luna, and openai/gpt-5.6-terra. Ofox’s GPT docs say openai/gpt-5.4-pro and the Codex ids are Responses-only, so this smoke test does not use them.

How to record a real run

  1. Copy the raw API key from the Ofox console. Do not add Bearer , quotes, or a trailing newline.
  2. From the repository root, export it in the current shell only. Do not commit it.
Shell
read -rs OFOX_API_KEY
export OFOX_API_KEY
python3 scripts/ofox-smoke.py

With a key, the script sends one Chat Completions request, one Responses request, and one Anthropic Messages request. The table above is still the Chat Completions model, latencyMs, status, httpStatus, and timestamp. With no key it prints BLOCKED_NO_OFOX_API_KEY, exits 0, and does not change the status file.

The Actions workflow “Ofox chat completions smoke” runs on demand. It reads the OFOX_API_KEY Actions secret. If that secret is empty, the job does not call Ofox and does not commit the status file.
