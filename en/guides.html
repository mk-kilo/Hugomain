GUIDE 01

Codex: model provider config

Codex CLI and the IDE extension read ~/.codex/config.toml. Official docs allow a model provider. The service still has to speak the protocol Codex uses and serve the model you name. Official config docs ↗

  1. Install and update official Codex, and confirm it runs on your machine.
  2. Open ~/.codex/config.toml and read the official docs for model_provider, model_providers and wire_api.
  3. Ask the API provider whether they support the Responses protocol Codex uses, the model id, and the auth scheme. OpenAI Chat Completions alone does not prove compatibility.
  4. Make a small test call. Check tool use, long output and stability before a large top-up.

GUIDE 02

Claude Code: LLM gateway

Claude Code calls the Anthropic API. Official docs allow an LLM gateway, and that gateway has to expose a compatible interface. Official gateway docs ↗

  1. Install from the official guide and complete a basic run first.
  2. Ask the provider whether they expose an Anthropic Messages gateway, tool calls, streaming, and which model ids.
  3. If they confirm that, the official variable shape looks like this. Use the values they give you:
Shell · example variables (not a working Ofox config)
export ANTHROPIC_BASE_URL="https://YOUR-COMPATIBLE-GATEWAY"
export ANTHROPIC_AUTH_TOKEN="YOUR_API_KEY"

Do not put an API key in GitHub or on a public page. Auth headers and paths differ by gateway. Follow the provider and the official docs.

Status: not verified. Do not put an OpenAI-only /v1 base URL into ANTHROPIC_BASE_URL. Claude Code is not launched by tests/ofox_smoke.py, and that test has not recorded a pass here.

GUIDE 03

Cursor: do not point it straight at Ofox

Cursor can store API keys for some providers. That setting does not cover every Cursor feature. Official API keys docs ↗

  1. Open Cursor Settings → Models. The menu moves between versions.
  2. Confirm the provider and model are in the official list, add the key as the page describes, and use Verify.
  3. Check whether a custom base URL is supported. For an aggregator, confirm the current Cursor version against that provider’s own notice.
  4. Test chat and edits you actually use. Tab completion and similar features may still use Cursor’s own service.
Status: Ofox marks this incompatible. Cursor Tab, Background Agent and Auto are not a fit for Ofox. TROUBLESHOOTING

When the call fails, check these first

401 Unauthorized?

Check that the key belongs to that API, that you did not copy a space, that the account has credit, and that the auth header matches the tool. Do not paste the key into a public post.

404 or model not found?

Check the path, the protocol and the model id. Codex Responses and a generic OpenAI-compatible chat endpoint are not the same feature. Claude Code needs an Anthropic-compatible gateway.

429 or rate limited?

Check balance, concurrency, token rate and upstream capacity. Slow the client down and retry.
