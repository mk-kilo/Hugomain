When not to use an aggregator

You use one model

The lab’s account is simpler, and an enterprise discount may be better. An aggregator earns its place when several models share one bill.

You need Cursor Tab, Agent or Auto

Ofox already says those features do not follow a custom API. Switching aggregators does not add Cursor’s official features back.

Compliance wants the lab’s signature

If the DPA, data residency or the invoice has to be with the model vendor, a reseller’s terms may not be enough. Read the documents before you add credit.

The tool has not run on your machine

Codex CLI and Claude Code are unverified here. tests/ofox_smoke.py has no recorded pass in this repo, and it does not launch either client.

The sticker and the checkout disagree

A claimed 0% fee, credit or bonus is only as real as the rule on the checkout you are looking at. Do not budget from a marketing page that disagrees with it.

You are treating a chat plan as an API

A ChatGPT, Claude or Cursor subscription is usually not third-party API credit. Buying API credit does not turn on those subscriptions.

Decide with three questions

The table above is what each public page said. This section is which column to read first. It adds no price, and it does not mark Ofox verified or cheaper.

1 · Chat plan, or API?

ChatGPT Plus and Claude Pro usually do not include API credit you can call from your own program. The API is another bill and another key. Read chat subscription vs API billing before you open an aggregator.

2 · Which protocol does the client need?

Codex’s provider config is not “Chat Completions exists.” Claude Code needs an Anthropic Messages gateway. An app on the OpenAI SDK usually only changes the base URL. A rate does not matter if the protocol does not match.

3 · Who has to sign?

One model, or a DPA, residency rule, or invoice that must be with the lab: stay on the official API. Several models on one account: then an aggregator is a candidate. OpenRouter on this page is an example of a published price list, not an invoice we paid.
