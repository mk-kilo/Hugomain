API ERRORS

Check 401, 404, 429, and timeouts in that order

This page is about OpenAI-compatible Chat Completions: root https://api.ofox.ai/v1, method path /chat/completions. Read the HTTP status and the body before you change the client. 401 Unauthorized

A 401 means the credential was rejected. Check these four items before you change the model.

  1. The header is Authorization: Bearer, one space, then the key. Do not send Bearer Bearer, and do not wrap the key in quotes.
  2. Trim spaces and newlines. A key copied from a web page often picks up a trailing line break.
  3. The key has to belong to the root you configured. A key for api.openai.com does not authorize api.ofox.ai, or the reverse.
  4. In the console that issued the key, confirm it was not revoked and that the account is allowed to call.

Do not paste the key into this site, a ticket, a chat, or a Git repository. Samples should show YOUR_API_KEY or an environment variable.

429

A 429 means the server asked you to slow down, or capacity is short. It is not a price list, and it does not say how much a model costs.

  1. Look for too much parallelism, or retries that fire again immediately.
  2. If the response includes Retry-After, wait that many seconds. When the header is absent, this page does not invent a delay.
  3. If the body talks about quota or billing, open the provider console. Providers do not all use the same status for an empty balance. This page does not assign one of them to Ofox.

Timeouts

Most timeouts are the client giving up, not an HTTP status from the server. See which side reported it.

  1. The client library says timeout: your limit is shorter than this generation. The official OpenAI SDK constructor accepts timeout in both Python and Node. Raise it above the time this reply needs. This page does not pick a number of seconds.
  2. HTTP 408 or 504: that status is on the path. Confirm the root answers, then look at the network between you and api.ofox.ai. This site does not publish a latency table.
  3. A long reply looks stuck: the Chat Completions body can set stream: true so chunks return as they are produced. That is a protocol field, not a speed this site measured.

Common errors

What should I check on a 401?

Confirm Authorization is Bearer, one space, then the key. Remove extra spaces, newlines, and quotes. The key has to belong to the account for the base URL you set. A key for api.openai.com will not authorize api.ofox.ai, or the reverse. Do not paste the key into a public page.

What should I check on a 404 or model not found?

SDK roots use https://api.ofox.ai/v1 with no extra /chat/completions. curl includes /chat/completions once. The model id has to come from that provider’s catalog, for example openai/gpt-5.4. A Responses-only model called through Chat Completions can also 404.

Does a 429 mean the price is wrong?

No. A 429 means the server asked you to slow down or is short on capacity. Lower concurrency, and honor Retry-After when that header is present. Billing questions belong in the provider console. This page does not assign Ofox a billing status code.

Is a timeout an HTTP status from the server?

Usually the client gave up first. Separate a client timeout from HTTP 408 or 504. The official SDK accepts a timeout value. This page does not prescribe a number of seconds. Chat Completions also has a stream field when you want tokens as they are produced.
