How to compare a price across countries

Separate the plan from the API

A chat membership usually does not include a developer API balance.

Match the plan and the channel

The website, the App Store, and Google Play can show different amounts and tax.

Read the checkout

Region, currency, tax, and renewal rules follow the provider’s checkout.

Calling more than one model from code?

A subscription price and a token price are different purchases. Compare the official API with an aggregator on the same model before you switch. This site does not fill in an Ofox rate, and it does not mark a call as verified.
