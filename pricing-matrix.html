常见问题

这些是今日最新的订阅价格吗？

不是。每条记录都有观测日期，属于历史样本。最新金额以你所在地区的官方或应用商店结算页面为准。

这些价格是否包含 API 消费？

不一定。App 会员与开发者 API 是不同的服务和计费方式。要比较 API，请进入开发者 API 成本比较器。

为什么有些产品没有价格？

公开数据覆盖不足时会标记“暂无核实数据”，不编造各地区价格。你仍可以进入该产品详情页核实官方价格。
