两种集成路径

API Key / Base URL 预设

仅在工具已支持自定义端点、经兼容性测试的前提下，增加 Ofox 作为可选 Provider。用户应自行在 Ofox 创建密钥；工具不可上传或内置共享密钥。

OAuth 2.1（Beta）

必须先向 Ofox 提交应用及回调地址，由平台开通 OAuth 应用后再实现授权与令牌管理。不能把推广链接伪装为 OAuth。

渠道归因

官方说明：仅首次通过渠道注册的新用户产生新归因；已有 Ofox 账号不会因授权或改用工具而改绑渠道。

发布前的检查清单

协议测试

真实验证 Chat Completions、Responses 或 Messages 中工具所需的协议，以及 streaming、工具调用和异常处理。

安全和权限

OAuth 必须使用官方注册回调；校验 state、PKCE、实际授予 scope；令牌放到安全存储。缺少 llm.invoke 时不可调用模型。

商业验证

确认模型实际标价、用户所属渠道、首充规则、服务支持和佣金能否统计。现有渠道收入不代表未来工具整合后的效果。
