团队限额、日志、路由和相关接口

下面只转述当天重新打开的 Ofox 文档和更新日志。用量返还或赠额比例以结账页为准。本站没有调用这些控制台开关，也没有调用视频或 Decisions 接口。

限额与访问 · 2026-11-09

更新日志「Team Management · Nov 9, 2026」和 Limits & Access 写的是同一组控制台入口：Settings → Limits & access。只有团队 Owner 和 Admin 能改规则，IP 允许列表、允许模型和预算的改动记在页面右上角的 Change history。日志保留设置不记在这份历史里。

  • 预算分团队、成员、API Key 三层，周期可以是 Daily、Monthly 或 Total。动作是 Notify and block，或 Notify only。任一层用尽，请求就会被拦住。同一周期内，Key 预算不能高于该成员的预算，成员预算不能高于团队预算。Ofox 写明：预算用尽之后，再充值也不会恢复调用；要提高上限，或等到日 / 月周期重置。
  • 团队 IP 允许列表只放行列出的 IPv4 或 CIDR，最多 100 条。Key 上的列表是在团队列表上再收窄；某个地址要同时在团队列表里才生效。不在列表上的地址会被拒绝，文档给出的代码是 403 ip_not_allowed。
  • 允许模型有三种：All models、Only these models、Block these models。Key 还可以再收窄。团队规则和 Key 规则要同时允许，模型才能调用。被拦住时文档给出的代码是 403 model_not_allowed。
  • 有效规则可以在 Key 菜单里预查某个模型会不会被拦住，以及还剩多少预算。Ofox 写明这次检查不使用 credits。

请求日志 · 2026-11-09

Request Logs 写明：默认零留存，不保存请求内容。需要排查时，Owner 或 Admin 从 Activity 右上角打开 Log retention，范围可以是全部 Key，或只保存选定的 Key。打开之后，新请求会保存输入、输出、工具调用和错误原因；图片要另外勾选 Also save images 才会保存。API Key、token、密码一类凭据在保存前换成 [REDACTED]。存储上限是最近 3 天、10,000 条请求或 1 GB，任一上限到达就自动删掉最旧的日志。单次跳过用请求头 X-OfoxAI-Log-Content: off。文档 FAQ 写日志保留不另收费。成员不能查看日志正文。

请求速率

限额页把请求速率标成只读，并指向 Rate Limits。这份速率文档写默认 RPM 为 100，按整个团队合计，同一团队的多把 Key 共用这一额度；更高额度联系 hi@ofox.ai。超出返回 429 Too Many Requests。更新日志 v1.1.0（2026-04-28）已经写过同一条团队合计和默认 100 RPM。

供应商路由 · 2026-08-26

更新日志「Provider Routing · Aug 26, 2026」开始记录可以用 provider.type 把一次请求钉到指定供应商。不填时按权重分配，单次落到哪一家不可预测。文本协议放在 extra_body.provider.type，也可以用请求头 X-OfoxAI-Provider-Type；Gemini 原生协议会忽略正文里的这个字段，只认请求头。视频用请求体顶层的 provider.type。未知名称返回 invalid_provider_type；该供应商不提供这个模型时返回 provider_type_unavailable。同一模型的内容策略可以不同，需要固定时就写明供应商。

当期 Provider routing 列出的名称是：openai、anthropic、gemini、azure_foundry（foundry）、aws_bedrock（bedrock）、google_vertex（vertex）、aliyun、alicloud、volcengine、byteplus、deepseek、moonshot、zhipu、zai、minimax、grok、jina、tencent。不是每个模型都由全部供应商提供。字段位置见 API · Provider routing。

Analytics · 2026-06-16

更新日志「Analytics · Jun 16, 2026」把原来分开的用量和费用并到一个 Analytics 页：调用量、花费和 token 在同一视图，可按模型、成员、API Key、应用切换，并支持自定义日期。入口写的是控制台 Analytics。这次请求 /docs/develop/observability/analytics.md 返回 404，所以上面以更新日志为准。

模型验真

模型验真 是免费工具，页面语言是中文。它向填写的中转接口做主动探测，把响应和已校准的 Claude、GPT、Gemini 行为特征比较。页面写明：高分只说明这次响应比较符合基准，不是身份证明，也不能证明接口背后的真实型号。更新日志 v1.0.47（2026-04-07）发布了这个工具；边界以 2026-11-26 打开的验真页为准。工具本身不收费，探测会向填写的接口发多次模型请求，服务商可能按其规则计费。

Video API 与 Decisions API

Video API 是异步接口：POST /v1/videos 创建任务并立即返回 202 和任务 id；GET /v1/videos/{id} 查到 completed、failed、cancelled 或 expired；DELETE /v1/videos/{id} 取消。认证头是 Authorization: Bearer。分辨率、时长和价格按模型变化，本页不列单价。

Decisions API 有文档。三个地址服务同一批模型，差别在请求格式：POST https://api.ofox.ai/v1/decisions、POST https://api.ofox.ai/openai/v1/decisions、POST https://api.ofox.ai/typesafe/v1/systemone。返回的是结构化判断（是/否、单选、评分），不是自由文本。文档表格列出 typesafe/jev-latest（文本或 JSON，不读图片）和可以读图片的 openai/gpt-6-luna。
