DON'T CONFUSE SUBSCRIPTIONS WITH API

Grok 订阅 ≠ xAI API 额度

SuperGrok 等订阅

主要面向在 Grok 应用或支持的产品中使用功能的个人。按地区、渠道及套餐产生订阅费用。

  • 一般按订阅周期支付
  • 可用功能取决于套餐与地区
  • 不应假定订阅费可抵扣 API 调用
Grok 官方产品 ↗

xAI 官方 API

面向程序调用、开发应用与自动化，按 xAI 当时公开的模型与用量规则计费。

  • 模型输入、输出等可能分项计费
  • 额度、限制与产品订阅分开
  • 适合需要编程接口的使用者

适合希望在一个平台管理多个厂商模型 API 的开发者，是否支持所需 Grok 模型、价格和协议必须单独核实。

  • 聚合管理的便利性是主要价值
  • 不承诺比 xAI 官方更低价

FREQUENTLY ASKED QUESTIONS

Grok 定价常见问题

SuperGrok 订阅可以拿来调用 API 吗？

不能默认相互通用。Grok 产品订阅和 xAI 开发者 API 分属不同计费体系，以官方账户和最新条款为准。

为什么不同国家的 Grok 订阅价格不同？

可能涉及 App Store 定价档、汇率、税费和当地策略。历史美元折算价只用于参考，不代表购买资格或当前实际价格。

选择价格最低的国家订阅是否划算？

不一定。除了标价，还需满足当地支付和平台地区要求。本站不建议提供虚假账单地址或规避服务条款。

Ofox 能使用 Grok 的所有模型吗？

不能仅凭聚合平台介绍断定。需要查询实时模型目录、价格、接口兼容性和服务条款。

不是。本站是独立内容和 Ofox 推荐推广网站，可能获得合规推荐佣金。
