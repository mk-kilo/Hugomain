如何完成下一轮验收

1 · 修正密钥

在 GitHub Actions Secrets 中保存原始 API Key，不包含 Bearer 前缀或换行，不公开密钥。

2 · 验证接口

运行 GitHub smoke test，核实返回 HTTP 状态、协议与模型实际输出；余额不足应与格式错误分开标识。

3 · 验证客户端

分别在 Codex CLI 和 Claude Code 执行真实任务，验证流式、工具调用及失败回退。
