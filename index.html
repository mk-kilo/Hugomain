新用户福利如何领取？

点击页面任意“新人优惠 / 获取 API Key”按钮，进入合作平台专属页面，按其页面展示的条件注册及参与活动。优惠资格和金额以实际活动规则为准。

JXZNE AI 会直接向我收费吗？

目前不会。第一阶段由 Ofox 合作平台提供账户、模型 API 和收费服务。JXZNE AI 可能从符合条件的推荐消费中获得推广收益。

现在就能调用模型吗？

点击“获取 API Key”会进入合作平台完成注册和充值，然后可使用统一 API 调用支持的模型。

为什么不直接在网页里保存 API Key？

静态网站不适合保存密钥。生产环境应把上游 API Key 放在安全的后端或密钥管理服务中。
